| 4 | 16px | Default element spacing, mobile padding |

| 6 | 32px | Layout gaps, tablet padding |
| 7 | 40px | Major element breaks |
| 8 | 48px | Large element spacing |
| 9 | 64px | Page-level spacing (mobile sections) |

### Font Stack

```css
font-family: Inter, ui-sans-serif, system-ui, -apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif;
```

### Rules

- Use large headlines with tight tracking (800-900 weight)
- Maximum paragraph width: 600-700px
- Short paragraphs, break headlines into intentional lines
- Never use tiny body text or long walls of text

## Component Specifications

### Cards

```css
background: #111111;
border: 1px solid rgba(255, 255, 255, 0.12);
border-radius: 24px;
padding: 24px-32px;
```

Hover:
```css
background: #171717;
transform: translateY(-4px);
border: 1px solid rgba(255, 255, 255, 0.22);
```

### Product Cards

- Image area dominates (aspect ratio: 4:5 or 1:1)
- Structure: Image → Product Name → Short Description → Price + Action
- Image radius: 20-24px

### Buttons

**Primary:**
```css
background: #FFD84D;
color: #0B0B0B;
border-radius: 999px;
font-weight: 800;
height: 52-60px;
padding: 20-28px;
```

**Secondary:**
```css
background: transparent;
border: 1px solid rgba(255, 255, 255, 0.22);
color: #FFFFFF;
border-radius: 999px;
```

**Interaction:**
- Default: scale(1)
- Hover: translateY(-2px)
- Active: scale(0.98)
- Arrow: translateX(3-5px)
- Transition: 180-250ms

### Navigation

Desktop: height 72-88px, sticky/fixed
Mobile: hamburger menu with full-screen drawer

### FAQ Component

Collapsed: Question + icon
Expanded: Question + answer below
Animation: 180-300ms

### Cart Drawer

- Right-side slide-in (420px desktop, full mobile)
- Backdrop overlay
- Escape key to close
- Body scroll lock when open

### Toast Notifications

- Auto-dismiss after 2.5s
- Success state for cart actions
- Non-blocking overlay

---

## Motion & Animation

### Scroll Reveal

Default:
```css
opacity: 0 → 1;
transform: translateY(24px) → translateY(0);
```

Duration: 500-800ms
Stagger: 50-120ms
Easing: cubic-bezier(0.22, 1, 0.36, 1)

### Hover Transitions

Standard: 180ms
Interactive: 250ms
Image zoom: scale(1.02-1.05)

### Large Visual Transitions

Duration: 500-800ms
Scroll reveal: 600-900ms

### Easing

Preferred: ease-out or cubic-bezier(0.22, 1, 0.36, 1)

### Reduced Motion

```css
@media (prefers-reduced-motion: reduce) {
  *, *::before, *::after {
    animation-duration: 0.01ms !important;
    animation-iteration-count: 1 !important;
    scroll-behavior: auto !important;
    transition-duration: 0.01ms !important;
  }
}
```

## Responsive Breakpoints

```css
--bp-xs: 320px;
--bp-sm: 390px;
--bp-md: 768px;
--bp-lg: 1024px;
--bp-xl: 1280px;
--bp-2xl: 1440px;
--bp-3xl: 1920px;
```

### Mobile (<768px)

- Fluid typography with clamp()
- Single column layouts
- Mobile navigation drawer
- Larger touch targets (44px minimum)
- Section spacing: 64-96px
- Padding: 16-20px

### Tablet (768-1024px)

- Two-column layouts where appropriate
- Reduced display typography
- Moderate section spacing
- Larger touch targets
- Padding: 32px

### Desktop (1280px+)

- Large editorial typography
- 12-column grid layouts
- Large visual compositions
- Generous whitespace
- Multi-column product grids
- Max content width: 1440px
- Padding: 32-64px

## Grain/Noise Overlay

```css
opacity: 0.03;
pointer-events: none;
```

Subtle texture only. Never heavy film grain.

---

## Image Treatment

- Natural lighting, realistic textures
- Strong subject separation
- Slight contrast, natural shadows
- Large image radius: 24-32px
- Product image radius: 20-24px

Avoid: Heavy HDR, over-saturated colors, AI-looking faces, plastic surfaces

---

## Marquee System

Horizontal continuous scroll:
- Speed: 20-35 seconds per loop
- Pause on prefers-reduced-motion
- Fade masks on edges

---

## Decorative Elements

- Circles, rings, lines, dots, arrows
- Oversized typography (opacity-5, background)
- Stickers, small labels
- Keep brand-relevant, not random fill

---

## Iconography

- Minimal line icons (lucide-react)
- Rounded strokes, simple geometry
- Sizes: 16px (small), 20px (standard), 24-32px (large)
- No mixing 3D icons + emoji + thin line icons

---

## Design Anti-Patterns (Never Use)

- Generic SaaS gradients
- Excessive glassmorphism
- Random neon colors
- Huge shadows everywhere
- AI-looking stock imagery
- Fake testimonials/statistics
- Excessive animations
- Tiny typography
- Low contrast
- Random fonts
- Inconsistent icon styles

## UI Considerations

| populated | CartDrawer (CartItem list) | ✅ covered | Cart items render with image, name, quantity controls, price |
